# 通信与控制接口 v1

## 1. 调试阶段输入方式

在 ESP32 板子到货前/手柄接入前，使用 USB 串口输入字母指令模拟控制输入。

| 串口输入 | 含义         | 等价手柄操作   |
| -------- | ------------ | -------------- |
| A        | 切换自动模式 | 按 AUTO 按钮   |
| M        | 切换手动模式 | 按 MANUAL 按钮 |
| S        | 普通停车     | 按 STOP 按钮   |
| E        | 急停         | 按 E-STOP 按钮 |
| F        | 前进         | 摇杆向前       |
| B        | 后退         | 摇杆向后       |
| L        | 左转         | 摇杆向左       |
| R        | 右转         | 摇杆向右       |

## 2. 正式阶段输入方式

正式阶段由物理手柄/遥控器输入，ESP32 读取手柄的摇杆和按钮状态，并转换成内部控制命令。

## 3. ESP32 内部统一命令

- CMD_AUTO_MODE
- CMD_MANUAL_MODE
- CMD_STOP
- CMD_EMERGENCY
- CMD_FORWARD
- CMD_BACKWARD
- CMD_LEFT
- CMD_RIGHT

## 4. 原则

不管输入来自串口、手柄还是手机，最终都要转换成统一控制命令，再交给状态机处理。
