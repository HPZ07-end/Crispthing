# 自主跟随机器人平台

> V1：履带小车手动遥控原型

本项目面向自主跟随机器人平台的软硬件开发。当前 V1 已完成 Arduino UNO、履带底盘、电机驱动扩展板和无线手柄的集成，可通过手柄实现小车前进、后退、原地左转、原地右转、停车及速度调节。

## 当前版本

- 项目阶段：V1 手动遥控版
- 推荐 Git 标签：`v0.1.0`
- 主控：Arduino UNO
- 底盘：双履带差速底盘
- 电机驱动：扩展板集成 TB6612
- 遥控方式：USB 无线手柄接收器 + I2C 转接板
- I2C 地址：`0x19`

## 已实现功能

- 手柄方向键控制前进、后退、左转和右转
- 松开方向键自动停车
- A 键停车
- X/Y 键调节速度
- 急停输入检测
- 急停释放后要求方向键回中，再次按键才能恢复运动
- 手柄断开或通信异常时停车
- 连续运动安全超时保护
- 串口调试输出
- 左右履带方向与电机通道校准

## 当前未启用功能

以下功能已预留接口，但不属于 V1 的验收范围：

## 工程结构

```text
target_follow_controller/
├── target_follow_controller.ino   # 主程序与控制循环
├── config.h                       # 引脚、速度和功能开关
├── remote_control.ino             # I2C 手柄通信与按键解析
├── safety_redundancy.ino          # 急停、超时和电机安全输出
├── obstacle_avoidance.ino         # 避障模块预留
└── auto_follow.ino                # 自主跟随模块预留
```

Arduino 会自动编译同一工程文件夹内的全部 `.ino` 文件。不要在主文件中手动 `#include` 其他 `.ino` 文件。

## V1 引脚分配

| 功能 | Arduino UNO 引脚 |
|---|---:|
| 左履带 PWM | D6 |
| 左履带方向 1 | D12 |
| 左履带方向 2 | D13 |
| 右履带 PWM | D5 |
| 右履带方向 1 | D7 |
| 右履带方向 2 | D8 |
| 遥控板 SDA | A4 |
| 遥控板 SCL | A5 |
| 急停输入 | A3 |

履带方向参数：

```cpp
#define LEFT_TRACK_DIR   1
#define RIGHT_TRACK_DIR -1
```

## 遥控按键

| 按键 | 功能 |
|---|---|
| 方向上 | 前进 |
| 方向下 | 后退 |
| 方向左 | 原地左转 |
| 方向右 | 原地右转 |
| A | 停车 |
| X | 降低速度 |
| Y | 提高速度 |
| START | 手动遥控模式 |
| SELECT | 自动模式预留 |

## 编译与上传

### 环境

- Arduino IDE 2.x
- 开发板：Arduino Uno
- 串口监视器：`115200 baud`
- `Wire` 为 Arduino 内置库，无需额外安装 PS2X 库

### 上传步骤

1. 关闭小车外部电源。
2. 仅通过 USB 将 Arduino UNO 连接电脑。
3. 使用 Arduino IDE 打开 `target_follow_controller.ino`。
4. 选择 `Arduino Uno` 和正确的 COM 端口。
5. 点击“验证”。
6. 点击“上传”。
7. 上传完成后，电机测试前拔掉电脑 USB。
8. 将履带架空，再连接 7.4 V 原装电池。

## 关键配置

在 `config.h` 中：

```cpp
#define MOTOR_ENABLED 1
#define SENSOR_ENABLED 0
#define TOF_ENABLED 0
#define EMERGENCY_STOP_ENABLED 1
#define I2C_REMOTE_ENABLED 1
```

V1 调试速度建议：

```cpp
const int MIN_SPEED = 70;
const int MAX_SPEED = 90;
```

## 安全说明

- 电机测试必须先将履带架空。
- 不要使用电脑 USB 长时间驱动电机。
- 烧录时关闭外部电池；电机测试时上传后拔掉 USB，再接电池。
- 急停 A3 当前属于软件急停，不能替代直接切断电机电源的硬件急停。
- 实车落地前，应增加额定电流合适的硬件断电装置。
- 遇到小车失控，应优先拔掉电池插头或切断上游电源。
- 不要带电插拔电机、传感器和遥控模块。
