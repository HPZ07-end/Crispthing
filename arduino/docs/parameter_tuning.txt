参数调试记录
============

履带底盘调参说明
----------------

由于本项目采用左右履带差速底盘，履带与地面的接触面积更大，转向阻力通常高于普通轮式底盘。

因此实车调参时需要重点关注：

MIN_SPEED:
  履带底盘低速时可能更容易卡住。
  如果低速指令下履带不动，可以适当增大 MIN_SPEED。

MAX_SPEED:
  第一版落地测试应设置较低，避免履带启动过猛。

K_TURN:
  履带转向阻力较大，但转向时也可能出现打滑。
  第一版建议先使用较小转向增益，再逐步增大。

TURN_SIGN:
  如果目标在右侧，但小车向左修正，则修改 TURN_SIGN。

LEFT_TRACK_DIR:
  如果左履带前进指令下实际后退，则改为 -1。

RIGHT_TRACK_DIR:
  如果右履带前进指令下实际后退，则改为 -1。

3. 参数含义
-----------

QUALITY_MIN:
  识别质量阈值。

  如果 quality 低于该值，小车停止。
  值越高，小车越谨慎，但可能更容易停。
  值越低，小车更容易继续跟随，但误识别风险更高。

SIZE_FAR:
  远距离阈值。

  如果 size 小于该值，认为目标可能较远。
  此时小车可以使用较高前进速度。

SIZE_NEAR:
  近距离阈值。

  如果 size 大于该值，认为目标可能太近。
  此时小车应停止或减速。

MIN_SPEED:
  最小跟随速度。

  如果小车低速时动不起来，可以适当增大。
  如果低速时仍然太快，可以适当减小。

MAX_SPEED:
  最大跟随速度。

  初次落地测试时应设置得比较低。
  确认安全后再逐步增大。

K_TURN:
  转向灵敏度。

  值越大，小车转向越敏感。
  值越小，小车转向越平缓。

TURN_SIGN:
  转向方向修正参数。

  如果实际测试中发现小车转向方向相反，
  可以将 TURN_SIGN 从 1 改为 -1。

TARGET_TIMEOUT_MS:
  目标数据超时时间。

  如果 Arduino 在该时间内没有收到新的 TARGET 数据，小车停止。

ULTRA_FRONT_SAFE_CM:
  前方 JSN-SR04 安全距离。
  前方距离小于该值时，小车停车。

ULTRA_SIDE_SAFE_CM:
  左右侧 JSN-SR04 安全距离。
  侧方距离小于该值时，限制对应方向转向。

ULTRA_REAR_SAFE_CM:
  后方 JSN-SR04 安全距离。
  后方距离小于该值时，禁止倒车。

TOF_TOO_CLOSE_CM:
  ToF 前向距离过近阈值。
  ToF 距离小于该值时，小车停车或减速。

TOF_FAR_CM:
  ToF 前向较远阈值。
  当目标接近画面中心且 ToF 距离大于该值时，可以使用较高前进速度。

TARGET_CENTER_X_THRESHOLD:
  判断目标是否接近画面中心。
  只有 abs(x) 小于该值时，ToF 更适合作为前向距离参考。


4. 急停相关说明
---------------

急停按钮不是调参项，而是安全输入。

当前默认急停引脚：

EMERGENCY_STOP_PIN:
  D13

接线逻辑：

按钮未按下：
  HIGH

按钮按下：
  LOW

急停触发后：
  小车立即停车。
  自动跟随、手动控制和绕障均不再执行。
