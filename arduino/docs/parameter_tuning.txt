参数调试记录
============

1. 文档作用
-----------

本文档用于记录小车实测过程中的参数调整。

主控程序中主要涉及以下参数：

QUALITY_MIN
SIZE_FAR
SIZE_NEAR
MIN_SPEED
MAX_SPEED
K_TURN
SAFE_DISTANCE_CM
TARGET_TIMEOUT_MS
TURN_SIGN


2. 当前默认参数
---------------

QUALITY_MIN:
  0.50

SIZE_FAR:
  0.08

SIZE_NEAR:
  0.30

MIN_SPEED:
  60

MAX_SPEED:
  160

K_TURN:
  90.0

SAFE_DISTANCE_CM:
  50.0

TARGET_TIMEOUT_MS:

  1


3. 参数含义
-----------

QUALITY_MIN:
  识别质量阈值。

  如果 quality 低于该值，小车停止。
  值越高，小车越谨慎，但可能更容易停。
  值越低，小车更容易继续跟随，但误识别风险更高。

SIZE_FAR:
  远距离阈值。

  如果 size 小于该值，认为目标可能较远。
  此时小车可以使用较高前进速度。

SIZE_NEAR:
  近距离阈值。

  如果 size 大于该值，认为目标可能太近。
  此时小车应停止或减速。

MIN_SPEED:
  最小跟随速度。

  如果小车低速时动不起来，可以适当增大。
  如果低速时仍然太快，可以适当减小。

MAX_SPEED:
  最大跟随速度。

  初次落地测试时应设置得比较低。
  确认安全后再逐步增大。

K_TURN:
  转向灵敏度。

  值越大，小车转向越敏感。
  值越小，小车转向越平缓。

SAFE_DISTANCE_CM:
  前方安全距离。

  当前主要用于距离传感器安全保护。
  当前方距离小于该值时，小车停止。

TARGET_TIMEOUT_MS:
  目标数据超时时间。

  如果 Arduino 在该时间内没有收到新的 TARGET 数据，小车停止。

TURN_SIGN:
  转向方向修正参数。

  如果实际测试中发现小车转向方向相反，
  可以将 TURN_SIGN 从 1 改为 -1。
