OpenBot 与 Arduino 串口通信协议
==============================

1. 文档作用
-----------

本文档用于说明 OpenBot 与 Arduino UNO 之间的串口通信格式。

在当前系统中：

OpenBot 负责：
- 获取摄像头图像
- 识别紫色背心
- 判断目标是否可见
- 计算目标在画面中的左右位置
- 估计目标大小
- 输出识别质量

Arduino 负责：
- 接收 OpenBot 发来的目标信息
- 解析目标数据
- 读取急停按钮状态
- 读取本地距离传感器数据
- 进行安全判断
- 计算左右轮速度
- 控制电机驱动板

Arduino 端融合的本地输入包括：
- 左侧 JSN-SR04
- 前方 JSN-SR04
- 右侧 JSN-SR04
- 后方 JSN-SR04
- 前向 ToF
- 急停按钮

OpenBot 不需要发送距离传感器数据或急停按钮状态。
这些数据由 Arduino 本地读取。


2. 消息格式
-----------

OpenBot 每次发送一行目标信息：

TARGET,visible,x,size,quality

示例：

TARGET,1,-0.25,0.12,0.85


3. 字段说明
-----------

TARGET:
  消息类型，表示这是一条目标识别数据。

visible:
  目标是否可见。

  1 表示识别到目标。
  0 表示目标丢失。

x:
  目标在画面中的水平偏移量。

  建议范围：
    -1.0 到 1.0

  含义：
    x < 0：目标在画面左侧
    x = 0：目标接近画面中心
    x > 0：目标在画面右侧

size:
  目标大小。

  当前主要来自紫色区域面积或目标框大小。
  只能用于粗略判断远近，不能作为准确距离。

quality:
  识别质量或置信度。

  如果 quality 太低，Arduino 应该让小车停止或进入安全状态。


4. 重要说明
-----------

摄像头估计的 size 不是准确距离。

size 会受到以下因素影响：

- 人的姿态变化
- 紫色背心被遮挡
- 光照变化
- 背景中出现紫色干扰
- 摄像头角度变化
- 人与摄像头之间的相对位置变化

因此：

- x 主要用于控制转向。
- size 只用于粗略控制前进速度。
- ToF 只在目标接近画面中心时辅助判断前向距离。
- JSN-SR04 主要用于四向避障安全保护。
- 急停按钮是最高优先级安全输入。
- Arduino 不应把 size 当成真实物理距离。


5. 示例消息
-----------

目标在画面中央，且看起来较远：

TARGET,1,0.00,0.05,0.90

目标在画面左侧：

TARGET,1,-0.40,0.10,0.90

目标在画面右侧：

TARGET,1,0.40,0.10,0.90

目标丢失：

TARGET,0,0.00,0.00,0.00

识别质量较低：

TARGET,1,0.10,0.10,0.20

目标看起来过近：

TARGET,1,0.00,0.40,0.90


6. 串口设置
-----------

波特率：
  9600

行结束符：
  Newline，即换行符

每条消息建议以换行符结束：

  \n
