Arduino 测试流程清单
===================

本文档用于指导 Arduino UNO 板子和小车底盘到货后的测试流程。


阶段 1：板子与 IDE 检查
----------------------

1. 上传 Blink 测试程序

程序位置：
  tests/test_00_blink/test_00_blink.ino

预期结果：
  Arduino UNO 板载 LED 闪烁。

如果失败，检查：
  - USB 线是否是数据线
  - Arduino IDE 是否选择 Arduino UNO
  - COM 口是否正确
  - 驱动是否安装成功
  - 是否有其他程序占用了串口


阶段 2：串口输出检查
--------------------

2. 上传 Serial Print 测试程序

程序位置：
  tests/test_01_serial_print/test_01_serial_print.ino

串口监视器设置：
  波特率：9600

预期结果：
  串口监视器每秒打印：
    loop running...


阶段 3：简单串口指令检查
------------------------

3. 上传 Serial Command 测试程序

程序位置：
  tests/test_02_serial_command/test_02_serial_command.ino

输入：
  f
  b
  l
  r
  s

预期结果：
  f -> Forward
  b -> Backward
  l -> Turn left
  r -> Turn right
  s -> Stop

目的：
  确认 Arduino 能接收并解析简单串口字符指令。


阶段 4：急停按钮检查
--------------------

4. 单独测试急停按钮接线。

建议接线：
  急停按钮一端接 D13
  急停按钮另一端接 GND
  代码使用 INPUT_PULLUP

预期逻辑：
  未按下：HIGH
  按下：LOW

检查内容：
  - 按下急停后，Arduino 能识别 emergencyStopActive。
  - 松开急停后，状态能恢复。
  - 后续启用电机前，必须先确认急停有效。


阶段 5：TARGET 数据解析检查
---------------------------

5. 上传 TARGET Parser Debug 测试程序

程序位置：
  tests/test_03_target_parser_debug/test_03_target_parser_debug.ino

串口监视器设置：
  波特率：9600
  行结束符：Newline

输入示例：

  TARGET,1,0.00,0.05,0.90
  TARGET,1,-0.40,0.10,0.90
  TARGET,1,0.40,0.10,0.90
  TARGET,0,0.00,0.00,0.00
  TARGET,1,0.10,0.10,0.20
  TARGET,1,0.00,0.40,0.90

预期检查：

  visible = 0：
    Arduino 应输出停止指令。

  quality 较低：
    Arduino 应输出停止指令。

  x < 0：
    Arduino 应产生一个方向修正量。

  x > 0：
    Arduino 应产生相反方向的修正量。

  size 较大：
    Arduino 应减速或停止。

  size 较小：
    Arduino 应输出较大的前进速度。

  TARGET 超时：
    Arduino 应输出停止指令。


阶段 6：OpenBot 到 Arduino 通信检查
----------------------------------

6. 连接 OpenBot 输出到 Arduino。

期望消息格式：

  TARGET,visible,x,size,quality

检查内容：
  - OpenBot 和 Arduino 的波特率是否一致
  - 每条消息后面是否有换行符
  - Arduino 是否能接收到完整消息
  - Arduino 是否能打印 visible、x、size、quality
  - 是否出现乱码或消息截断


阶段 7：电机驱动检查
--------------------

7. 上传 Motor Driver 测试程序

程序位置：
  tests/test_04_motor_driver_test/test_04_motor_driver_test.ino

测试前准备：
  1. 确认电机驱动板接线。
  2. 根据实际接线修改代码中的电机引脚。
  3. 将小车轮子架空。
  4. 使用低速测试。
  5. 先确认急停按钮有效。
  6. 将电机测试使能标志设置为 1。

测试指令：
  lf -> 左履带前进
  lb -> 左履带后退
  rf -> 右履带前进
  rb -> 右履带后退
  ff -> 双履带前进
  ss -> 停止

预期结果：
  - 左电机可以正转和反转。
  - 右电机可以正转和反转。
  - 停止指令有效。
  - 急停按钮按下后电机立即停止。
  - 记录真实电机方向。


阶段 8：距离传感器检查
----------------------

8. 上传 Distance Sensor 测试程序

程序位置：
  tests/test_05_distance_sensor_test/test_05_distance_sensor_test.ino

依次测试：

1. 左侧 JSN-SR04
2. 前方 JSN-SR04
3. 右侧 JSN-SR04
4. 后方 JSN-SR04
5. 前向 ToF

检查内容：
- 每个 JSN-SR04 的距离值是否随障碍物变化。
- 多个超声波不要同时触发，应按顺序读取。
- ToF 是否能稳定输出前方距离。
- 无效读数是否返回 -1。


阶段 9：主控程序检查
--------------------

9. 上传主控程序

程序位置：
  target_follow_controller/target_follow_controller.ino

第一次测试时保持：

  MOTOR_ENABLED = 0
  SENSOR_ENABLED = 0
  DEBUG_PRINT = 1

检查内容：
  - TARGET 数据能否被正确解析。
  - 左右轮速度指令是否被正确打印。
  - 目标超时是否触发停止。
  - 目标丢失是否触发停止。
  - quality 太低是否触发停止。
  - size 过大是否触发减速或停止。
  - 急停按钮是否触发 EMERGENCY 状态。


阶段 10：启用距离传感器安全保护
-------------------------------

10. 启用距离传感器。

只有在单独测试通过后，才能设置：

  SENSOR_ENABLED = 1

检查内容：
  - 前方过近是否停车。
  - 左侧过近是否限制左转。
  - 右侧过近是否限制右转。
  - 后方过近是否禁止倒车。
  - ToF 是否只作为前向辅助测距。


阶段 11：启用电机输出测试
-------------------------

11. 启用电机输出。

只有在确认接线无误、急停有效后，才能设置：

  MOTOR_ENABLED = 1
  
测试时必须让履带离地或底盘架空。
检查内容：
  - 左履带方向是否正确
  - 右履带方向是否正确
  - 停止指令是否有效
  - 如果转向方向相反，修改 TURN_SIGN
  - 如果单侧履带前后方向相反，修改 LEFT_TRACK_DIR 或 RIGHT_TRACK_DIR


阶段 12：低速落地测试
---------------------

12. 低速落地测试。

落地测试前建议降低速度参数：

  MIN_SPEED = 40
  MAX_SPEED = 100

检查内容：
  - 目标丢失后是否停车。
  - quality 过低时是否停车。
  - 目标在左/右侧时，转向是否正确。
  - 目标过近时是否停车。
  - 前方障碍过近时是否停车。
  - 急停按钮是否能立即停车。
  - 是否存在失控冲出的问题。
