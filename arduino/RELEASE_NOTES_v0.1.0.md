# V1 手动遥控版发布说明

## Git 标签

推荐：`v0.1.0`

## 版本定位

这是自主跟随机器人平台的第一个可运行原型版本。当前版本重点验证底盘、电机驱动、无线手柄、Arduino 控制框架和基础安全逻辑，尚未启用自主跟随与避障功能。

## 新增功能

- 完成 Arduino UNO 与商家电机扩展板适配
- 确认真实电机引脚：
  - 左履带：D6、D12、D13
  - 右履带：D5、D7、D8
- 完成左右履带方向校准
- 实现 I2C 无线手柄控制
- 实现前进、后退、原地左转和原地右转
- 实现松键停车、A 键停车和速度调节
- 实现急停输入及释放后回中解锁
- 实现遥控通信异常停车和连续运动安全限制
- 完成 7.4 V 电池架空实车测试

## 已知限制

- 急停目前为软件急停，Arduino 死机时不能保证切断电机电源
- 避障传感器尚未启用
- 自主跟随尚未启用
- 连续运动安全时限需要根据实车需求继续调整
- 落地测试和负载测试尚未完成

## 下一版本目标

V2 将重点完成超声波/ToF 传感器接入、前方障碍检测、减速停车及基础绕障逻辑。
